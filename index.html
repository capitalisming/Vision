Vision self-check prototype

Visual acuity self-check

A Landolt C acuity test that scales each sign to your distance from the screen. Pilot prototype for monitoring functional vision change; it is not a medical device.

  1. Calibrate the screen with a bank card.
  2. Optional: calibrate the camera for distance tracking.
  3. Set up a session and run the test.
