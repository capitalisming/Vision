# 02 · Экспериментальный протокол

Версия 1.0 · 2026-11-14 · приложение `app` v0.1.0

Протокол написан с нуля: в материалах проекта его не было. Изменение исходной проверки «за вечер» объяснено в `01_materials_audit.md`, проблема **P1**. **Протокол E1 требует подтверждения автора проекта до начала опытов.**

Критерии успеха и правила обработки зафиксированы **до** сбора данных. После получения данных их не меняют. Любое отклонение записывают в журнал как отклонение.

## Общие условия для всех опытов

| Параметр | Значение | Зачем |
|---|---|---|
| Устройство | один и тот же телефон во всех сессиях участника; ≥ 400 ppi | сопоставимость; мелкие знаки рисуются физически (C1) |
| Яркость | максимальная; автояркость, ночной режим и True Tone выключены | постоянный контраст |
| Освещение | обычный комнатный свет, без бликов на экране; одно и то же место | размер зрачка влияет на глубину резкости |
| Расстояние | 40 см (окно 36–44 см контролируется камерой) | аккомодационная нагрузка 2,5 D ± 0,25 D |
| Коррекция | участник в своих обычных очках/линзах **для дали** (если носит) | исходная точка «как в жизни» |
| Монокулярно | второй глаз закрыт ладонью, без давления; порядок OD → OS | стандарт; давление на глаз временно ухудшает зрение |
| Масштаб страницы | не трогать (масштабирование запрещено в приложении) | физический размер знака |
| Калибровка | экран: карта ID-1 (короткая сторона), 1 раз на устройство; камера: рулетка 40 см, 1 раз на участника | см. `01`, раздел 4 |

**Безопасность.** Все линзы — обычные очковые, без лекарств и капель. Через сильные плюсовые линзы предметы вдали размыты, поэтому **в них нельзя ходить**: участник сидит. Если появятся головная боль или тошнота, опыт прекращается. Детям до 12 лет без согласия родителей участвовать нельзя. Это немедицинский опыт, диагноз не ставится.

**Регистрация.** Для каждого прогона приложение сохраняет все предъявления: размер знака в пикселях и мм, расстояние в начале и в момент ответа, три сырые оценки расстояния, ответ, время реакции, яркость кадра. Экспорт: «История → Экспорт JSON» и «CSV». Ручной журнал ведётся по шаблону `docs/templates/experiment_log.csv`: ID опыта, время, участник, условия, отклонения, сбои. **Неудачные прогоны не удаляются.**

## E0 · Точность измерения расстояния камерой

**Цель.** Проверить ключевое утверждение: «камера следит за расстоянием, поэтому результат не зависит от того, как держат устройство».

**Оборудование.** Телефон, рулетка (желательно жёсткая), помощник.

**Порядок.**
1. Откалибровать камеру на 40 см («Начать калибровку → Шаг 2»).
2. Открыть «Проверка расстояния (опыт E0)».
3. Для каждого условия (оба глаза открыты / левый закрыт ладонью / правый закрыт ладонью) и каждого расстояния 30, 35, 40, 45, 50 см (по рулетке, от наружного угла глаза до плоскости экрана) нажать «Записать». Каждая запись — это 1,5 с, медиана кадров.
4. Порядок расстояний внутри условия случайный. Всего 3 × 5 = 15 точек на участника.

**Анализ.** Бланд–Альтман (камера − рулетка): смещение, 95% пределы согласия, отдельно по каждому условию (`run_analysis.py`, `fig_distance_agreement`).

**Критерий успеха (заранее).** В условиях «один глаз закрыт» пределы согласия на 36–44 см укладываются в ±2 см, то есть ±0,02 logMAR. Тогда ошибка расстояния пренебрежимо мала по сравнению с погрешностью теста (~0,06 logMAR).

## E1 · Проверка линзами (за один вечер)

**Цель.** Проверить, что тест ловит оптическое ухудшение зрения вблизи и что сигнал растёт с силой расфокусировки.

**Принцип (см. C2).** Знак находится на 40 см, нужна аккомодация 2,5 D. Плюсовая линза силой P до +2,5 D лишь снимает эту нагрузку, и острота **не должна** меняться: это отрицательный контроль. Линза сильнее +2,5 D создаёт расфокусировку P − 2,5 D, которую аккомодация убрать не может. Острота **должна** ухудшаться тем сильнее, чем сильнее линза.

**Оборудование.** Аптечные очки для чтения +1,0; +2,0; +2,5; +3,0; +3,5; +4,0 D. Если возможно, проверить их силу на диоптриметре в оптике и записать фактическое значение. Если участник носит очки для дали, лучше использовать контактные линзы. Если их нет, держать очки для чтения поверх своих и отметить это в заметке.

**Участники.** Минимум 3, лучше 5–8 взрослых. Возраст записывается: у людей после 40 лет порог P0 может сместиться, это ожидаемо.

**Порядок (~25 мин на участника).**
1. Режим «Эксперимент», участник `P01`…, ID опыта `E1`.
2. **B1, B2:** два прогона без добавочной линзы (поле «Добавочная линза» = 0).
3. Шесть прогонов с линзами в **случайном порядке**: порядок взять из `docs/templates/e1_lens_orders.csv`, своя строка на каждого участника. В поле линзы указать силу.
4. **B3:** финальный прогон без линзы (проверка усталости и обучения).
5. Перерыв 1 мин между прогонами. Оба глаза в каждом прогоне.

**Анализ (`run_analysis.py`).**
- Личная норма = B1–B3 (валидные), правило из приложения.
- Для каждой линзы: Δ = logMAR − норма; «обнаружено» = Δ > предела.
- Монотонность: ρ Спирмена между силой линзы и logMAR для P ≥ 2,5 D.
- Подгонка модели logMAR = log10(√(MAR0² + (c·max(0, P − P0))²)) — **разведочная**. По симуляции S3 излом P0 восстанавливается с ошибкой до ±0,55 D при шаге линз 0,5 D, поэтому P0 и c не используются как критерий.

**Критерии успеха (заранее, по каждому глазу).**
1. Линзы +1,0 и +2,0 D **не** вызывают срабатывания у ≥ 80% глаз (специфичность метода).
2. Линзы +3,5 и +4,0 D вызывают срабатывание у ≥ 80% глаз (чувствительность к расфокусировке ≥ 1,0 D).
3. ρ Спирмена > 0 для P ≥ 2,5 D у ≥ 80% глаз (рост сигнала с дозой).
4. |B3 − среднее(B1, B2)| < предела у ≥ 80% глаз (нет заметного дрейфа за вечер).

Если критерий не выполнен, это **результат**, а не повод менять критерий.

**Ожидаемая картина (симуляция S3, SIMULATED, не данные):** +1,0 и +2,0 D: 0/8 срабатываний; +2,5: 2/8; +3,0: 7/8; +3,5 и +4,0: 8/8.

## E2 · Разброс между днями (личная норма)

**Цель.** Измерить реальный разброс между днями, который нужен правилу «изменение больше собственного разброса» (P4 в аудите).

**Порядок.** Режим «Мониторинг», «Свои очки». Один тест в день, в одно и то же время суток, 5–7 дней подряд. Каждый день освещение и место те же.

**Анализ.** Внутрисубъектное SD Sw между днями, коэффициент повторяемости CoR = 2,77·Sw, Бланд–Альтман (день 2 − день 1), тренд по дням (эффект обучения).

**Критерий.** Без порога «успеха»: E2 даёт параметр. Если Sw > 0,08 logMAR, правило с σ0 = 0,06 слишком оптимистично, и σ0 нужно пересмотреть.

## E3 (по возможности) · Имитация SANS у людей с пресбиопией

**Цель.** Прямо проверить сценарий SANS: гиперметропический сдвиг у человека с малым запасом аккомодации.

**Участники.** 50 лет и старше, в своих очках для чтения. **Линзы.** Минусовые −0,5; −1,0; −1,5 D из пробного набора оптики (аптечных минусовых нет). Порядок такой же, как в E1.

**Предсказание (C2, CALCULATED).** Срабатывание начинается, когда сдвиг превышает остаточный запас аккомодации, то есть индивидуально. У молодых людей та же процедура срабатывать **не должна**: это демонстрация ограничения P2.

## Что записывать при отклонениях

В `experiment_log.csv` записываются: прерванный прогон и его причина; «лицо не видно камере» дольше нескольких секунд; ответы по ошибке; смена освещения; давление на глаз; линза не той силы. Прогон не удаляют. Анализ включает все валидные прогоны и отдельно перечисляет невалидные.
